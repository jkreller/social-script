# Social Script Runner — Frontend

A React PWA that guides a user through a social script step by step. Runs against the FastAPI backend in `../api/`.

## Run locally

**1. Start the backend** — see [`../api/README.md`](../api/README.md).

**2. Install dependencies and start dev server**:

```bash
npm install
npm run dev
```

Open the printed URL in a browser (or on a phone on the same network using your machine's LAN IP).

## Environment variable

| Variable | Default | Description |
|---|---|---|
| `VITE_API_URL` | `http://localhost:8000` | Base URL of the FastAPI backend |

Set this in `.env.local` for local overrides, or as a build-time env var in your hosting platform.

## Build

```bash
npm run build   # outputs to dist/
npm run preview # locally preview the production build
```

## Deploy to Vercel

1. Push the repo to GitHub.
2. Import the project in Vercel. Set:
   - **Root directory**: `frontend`
   - **Framework preset**: Vite
3. Add an environment variable:
   - `VITE_API_URL` → URL of your deployed FastAPI backend (e.g. a Railway or Fly.io deployment)
4. Deploy. The PWA manifest is auto-generated by `vite-plugin-pwa` — the app is installable on iOS and Android from the browser.

## Install as a home screen app

- **iOS**: Open in Safari → Share → Add to Home Screen
- **Android**: Open in Chrome → three-dot menu → Add to Home Screen (or the install prompt)

Once installed, the app runs in `standalone` mode: fullscreen, no browser chrome.
